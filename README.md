# Pizza Sales Analysis using SQL

SQL-based analysis of a pizza sales dataset, answering business questions 
like top-selling pizzas, peak order times, and revenue trends using SQL queries.

## About
This project uses SQL queries to explore and analyze pizza sales data, 
covering aggregations, joins, and business-focused questions such as 
top-selling pizzas, revenue trends, and order patterns.
